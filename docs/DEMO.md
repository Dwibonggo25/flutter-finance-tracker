# Portfolio demo checklist

Use this short flow when recording a 45–60 second portfolio demo:

1. Sign in and show the dashboard balance and animated financial chart.
2. Add, edit, search, and delete a transaction.
3. Set a monthly category budget and show its warning state.
4. Open the bell, add a recurring bill, and enable its due-date reminder.
5. Open Reports, change period/category filters, then export CSV and PDF.
6. Switch Indonesian/English to demonstrate localization.

Recommended screenshots:

- Dashboard with realistic sample data
- Transaction CRUD form and list
- Budget warning state
- Recurring transaction reminder list
- Animated report and export menu
- QRIS portfolio screen

Never include real account balances, email addresses, API keys, or Firebase
configuration values in portfolio media.
